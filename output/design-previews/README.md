# BBCA annual comparison design previews

Both PDFs use the same reviewed BBCA analysis snapshot and cover the annual history from 1998 through 2025, plus a separate 2026 interim page. The mockups are alternative layouts for review, not separate data sets.

- **Design A — The Annual Ledger** is a seven-page, landscape report. It groups the full year-by-year matrix into earnings, funding and reinvestment, valuation, and shareholder outcomes.
- **Design B — The Year Card** is a 31-page, portrait report. It has a glossary, one comparison page for each year, and a separate 2026 update.

Both keep price change distinct from dividend-inclusive return, label the 2000 listing year, adjust per-share figures to the October 2021 split basis where reviewed values support it, and keep 2026 consolidated and bank-only periods separate. A blank means the reviewed data do not support a comparable value.
