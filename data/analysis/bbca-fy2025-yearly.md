## 2025 — BCA earned more while its shares fell

- **At the bank.** BCA lent more and earned more from its operations. It also booked higher charges for potential losses, which held back profit growth. Group profit increased from the year before.

- **For shareholders.** The share price fell. Cash dividends softened the decline, but the annual return remained negative.

- **Why it mattered.** Dividends cushioned part of the loss. By year-end, investors were paying less for each rupiah of annual profit than they had a year earlier.

## 2020 — The pandemic interrupted profit growth

- **At the bank.** BCA reworked payment terms for affected borrowers. Lending contracted on the bank's published comparison and charges for potential losses rose. Group profit declined from the year before.

- **For shareholders.** The share price rose, and cash dividends added to the full-year return.

- **Why it mattered.** Loan relief gave borrowers more time to pay. Higher loss charges reduced current profit even as customer deposits grew. The shares ended the year slightly higher.

<a id="yearly-glossary"></a>

## Table legend and glossary

Definitions and calculation bases used in the year-by-year tables. Read each result with its reporting scope and period.

| Term | Meaning in this report |
| --- | --- |
| **REPORTING SCOPE AND PERIODS** |  |
| Group | BCA and its subsidiaries, reported on a consolidated basis. |
| Bank only | BCA parent bank without subsidiaries. Do not combine with group figures. |
| FY | Full financial year. Profit and expenses cover the year; balance-sheet ratios describe a date. |
| YTD | Year to date, compared with the same months of the prior year. |
| As filed / restated | As-filed values preserve the original report. Restated values reflect later corrections or reclassifications. |
| **UNITS AND COMPARISON** |  |
| IDR T | Trillion Indonesian rupiah. |
| pp | Percentage points: the arithmetic difference between two percentages. |
| × | Times, used for valuation multiples such as price-to-earnings. |
| Change | Money amounts show percentage growth; ratio measures use pp; EPS uses rupiah per share; multiples use ×. Negative-to-positive changes are stated in words. |
| Level only | No comparable prior-period value is available on the same basis. |
| **BANK AND PERFORMANCE MEASURES** |  |
| CASA | Current and savings accounts; a lower-cost source of customer deposits. |
| NIM | Net interest margin: net interest income relative to earning assets. |
| NPL / LAR | Non-performing loans / loans at risk. These use different definitions; compare only matching scope and basis. |
| CAR | Regulatory capital as a share of risk-weighted assets. |
| LCR / NSFR | Liquidity coverage over a 30-day stress period / stable funding available against longer-term needs. |
| ROA / ROE | Profit relative to average assets / average shareholders’ equity. |
| **SHAREHOLDER MEASURES** |  |
| EPS | Earnings per share. EPS and share-price figures use the October 2021 split-adjusted share basis. |
| P/E / P/B | Share price compared with earnings per share / book value per share. |
| Share-price return | Calendar-year change in split-adjusted share price; dividends excluded. |
| Total return | Share-price change plus cash dividends, before tax and trading fees. |
| Dividend yield / payout | Cash dividends relative to share price / earnings per share. |
| Real return | Total return adjusted for Indonesian CPI inflation over the same calendar year. |
