# Financial reporting

Financial reports present reviewed company results, comparisons, and sources in a consistent reading order.

## Language

**Yearly report**
An ordered report with current-period analysis, annual comparisons from newest to oldest, and a glossary.

**Standard Template 1**
The reusable layout for a yearly report, with a linked cover, period comparisons, and sources after each section’s tables.

## Relationships

- A yearly report uses a report template and supplies company-specific sections.
- Standard Template 1 can present reports for banks and other companies.
